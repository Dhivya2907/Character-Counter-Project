# Character-Counter-Project

Description 
A simple text area that counts characters as the user types and displays the remaining characters allowed.

Features 
Allows the user to type a message.
Sets a maximum limit of 200 characters. 
Updates the character count in real time. 
Displays the number of characters typed, such as 150/200 characters. 
Displays the number of remaining characters. 
Shows an alert when the maximum character limit is reached. 
Prevents the user from typing more than 200 characters.

Technologies Used 
HTML 
JavaScript
